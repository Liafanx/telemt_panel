# Адрес подключения в ссылке

По умолчанию панель использует адрес из готовых ссылок Telemt. Если задан
`general.links.public_host`, это он; иначе адрес выбирает сам Telemt.

Если нужен выбор между общим DNS RR-доменом и адресом отдельного сервера:

1. Откройте **Сервер → Настройки панели → Адреса в ссылках**.
2. Включите **«Разрешить выбор адреса подключения»**.
3. Откройте пользователя и вкладку **«Доступ»**.
4. В списке **«Адрес подключения»** выберите исходный адрес или один из доменов
   из `censorship.tls_domains` конфигурации Telemt.

Опция по умолчанию выключена. Это общая настройка панели, сохранённая в
`panel-state.json`: перезапуск не нужен, SQLite не требуется.

Выбор меняет только параметр `server` в отображаемой ссылке, её QR-коде
и кнопках копирования внутри этого блока. Порт, секрет и домен TLS-маскировки
не меняются. Конфигурация Telemt также не изменяется.

**Домен маскировки не обязан вести на ваш сервер.** Выбирайте его в качестве
адреса подключения только если соответствующая DNS-запись ведёт на нужный
сервер или пул. Панель не проверяет и не настраивает DNS.

При повторном открытии вкладки, смене пользователя или варианта ссылки снова
используется исходный адрес. Если список доменов не удалось загрузить, подмена
не применяется. Исходные ссылки остаются доступны.

Быстрые кнопки списка и шапки пользователя, страница подписки и ссылки WEB
продолжают использовать свои исходные адреса. WEB привязан к домену своего
профиля и в этот выбор не входит.
